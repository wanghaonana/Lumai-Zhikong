# Third-party components and provenance

This project contains an independently implemented local demonstration application and bundled third-party runtime dependencies. Retain this file and the accompanying notices when sharing it.

- Cologne8 road network and original trips: SUMO-RL's RESCO scenario directory, https://github.com/LucasAlegre/sumo-rl/tree/main/sumo_rl/nets/RESCO/cologne8. The pinned commit is recorded in `scenario/source.json`. The data's accompanying `Creative Commons Legal Code.pdf` is retained without modification. RESCO/TAPAS Cologne are the upstream scenario origins.
- Eclipse SUMO 1.27.1: https://eclipse.dev/sumo/ . Binary runtime and TraCI/sumolib tools are reused from the locally available reference project's portable runtime. SUMO's `LICENSE` and `NOTICE.md` are retained under `runtime/sumo/`. This includes third-party DLLs required by the supplied SUMO distribution.
- CPython 3.12 portable runtime: Python Software Foundation. `runtime/python/LICENSE.txt` and the distribution files are retained.
- NumPy 2.2.6: official PyPI wheel for CPython 3.12 / Windows AMD64. Installed package includes license and distribution metadata.
- Flask and its installed dependencies are retained with their package distribution metadata in `runtime/python/Lib/site-packages/`.

The application does not copy the reference BYD project's interface or prediction code. The new road network, model weights, controller, interface, tests and documentation are supplied in this directory. Traffic demand and evaluation outputs generated by the application are synthetic simulation data.
