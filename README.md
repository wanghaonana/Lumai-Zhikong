## 下载与启动

1. 点击仓库的 **Code → Download ZIP**，完整解压到本地文件夹（不要在压缩包内运行）。也可执行 `git clone https://github.com/wanghaonana/Lumai-Zhikong.git`。
2. 在 **Windows 64 位**电脑上双击根目录的 `启动演示.cmd`，无需另装 Python 或 SUMO。
3. 浏览器打开 `http://127.0.0.1:8878`。首次启动会生成车流并预热仿真，请稍候。
4. 结束时双击 `关闭演示.cmd`；关闭网页不会停止后台服务。

详细操作见 [使用说明](使用说明.md)，算法与边界见 [算法说明](算法说明.md)，随包测试记录见 [模拟测试报告](模拟测试报告.md)，第三方组件来源与许可位置见 [THIRD_PARTY.md](THIRD_PARTY.md)。

`runtime/` 是便携版随附运行环境；`models/` 保存模型与预测误差记录；`scenario/` 保存路网、路线池和来源；`outputs/` 保留压缩包中的合成仿真数据与评估记录。下载时请保留目录结构。

重新训练与评估可双击 `重新训练与测试.cmd`；运行现有集成测试可在项目目录执行：

```powershell
.\runtime\python\python.exe -B .\tests\test_integration.py
```

## 项目简介

“路脉智控”面向事故、施工、天气扰动与交通需求变化等复杂条件，研究道路**可服务供给**、**预计到达需求**和**交通调控反馈**之间的关系。在统一道路边与时间窗口内计算供需状态，并在交通仿真中比较不同调控方案的运行表现。

演示原型以德国科隆 **Cologne8 公共城市路网结构**为基础，以**合成交通需求**开展 SUMO 仿真；真实路网几何结构不代表使用了科隆现场实测流量。场景来源见 `scenario/source.json`，原包附带的许可文件位于 `scenario/Creative Commons Legal Code.pdf`。

## 系统技术路线

```text
Cologne8 路网 + 合成交通流 + 事件 / 天气 / 车辆组成
                    │
        多环境扰动与运行状态分析
                    │
    ┌───────────────┴───────────────┐
    │                               │
动态道路供给估计                未来交通状态预测
车头时距 / 信号 / 下游约束       路网邻接 / 历史状态 / 环境
    │                               │
    └───────────────┬───────────────┘
                    ▼
         供需差额与失衡风险分析
                    │
       信号参数调度 + 动态路径分流
                    │
        SUMO / TraCI 双组仿真反馈
                    │
            网页可视化与评价
```

核心创新设计与演示对应关系：

1. **多环境扰动下的供需双向建模**：事件、雨天和需求变化同时作用于环境参数、供给约束和需求状态。
2. **考虑车辆自主化比例的供需协同预测**：混合交通容量先验结合历史路段状态、上下游邻接特征与环境状态，支持未来 5–60 分钟交通状态预测。
3. **可解释动态匹配与反馈评估**：根据供需缺口、排队和下游约束调度信号参数、调整路径，并记录调控动作与仿真指标。

**当前研究原型**采用混合车头时距供给估计、轻量图状态残差预测与预测驱动的信号/路径调控，并未宣称已实现 Transformer 或完整 MPC 最优控制；元胞模型与 Transformer 属于后续拓展与对比方向。

## 已有 Demo 的研究描述

演示原型包括 Python、Flask、SUMO 1.27.1 与 TraCI，采用 Cologne8 的 **149 条道路边、8 个信号路口**；页面提供：

- 图结构道路交通状态可视化，查询流量、速度、密度和排队；
- 未来 12 个五分钟窗口（5–60 分钟）的交通状态预测；
- 事故瓶颈、雨天施工、需求突增的场景控制；
- 固定信号与智能调控两个相同输入条件下的仿真组；
- 策略日志、曲线与 JSON/CSV 结果导出。

对应实现见 `network.py`、`predictor.py`、`engine.py`、`server.py` 与 `web/`，集成测试位于 `tests/test_integration.py`。运行环境面向 Windows，当前启动器未适配 Linux / macOS。

## 初步仿真结果（不等于现场实测）

根据项目计划书，每类场景 3 个随机种子，完整调控方案相对于固定信号方案报告：

| 场景 | 平均累计延误下降 | 排队积分平均下降 |
| --- | ---: | ---: |
| 事故瓶颈 | 18.24% | 23.19% |
| 雨天施工 | 5.41% | 9.68% |
| 需求突增 | 13.49% | 2.80% |

这些结果只对应选定路网和**合成交通条件**；并非全部指标均有提升，控制模块的独立贡献、容量估计真值与跨路网推广性仍需验证。随包评估摘要见 `outputs/validation_summary.json`，逐次输出见 `outputs/evaluation_*.json`，实验脚本见 `train_validate.py`。上传项目本身不等于重新运行全部训练与评估。
