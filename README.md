# 路脉智控 · Lumai-Zhikong

**面向复杂交通环境的道路供需协同预测与动态调控系统**  
*Road Supply–Demand Cooperative Prediction and Dynamic Traffic Control*

> **Release status / 发布状态：项目介绍已发布，原始 Demo 代码仍在整理中。当前仓库尚不能独立部署运行。**  
> This repository currently contains project documentation. The runnable demo source and redistribution-cleared assets have **not yet been released**.

## 项目简介

“路脉智控”面向事故、施工、天气扰动与交通需求变化等复杂条件，研究道路**可服务供给**、**预计到达需求**和**交通调控反馈**之间的关系。在统一道路边与时间窗口内计算供需状态，并在交通仿真中比较不同调控方案的运行表现。

已有演示原型以德国科隆 **Cologne8 公共城市路网结构**为基础，以**合成交通需求**开展 SUMO 仿真；真实路网几何结构不代表使用了科隆现场实测流量。后续将核查第三方路网文件的再分发许可。

## 系统技术路线

```text
Cologne8 路网 + 合成交通流 + 事件 / 天气 / 车辆组成
                    │
        多环境扰动与运行状态分析
                    │
    ┌───────────────┴───────────────┐
    │                               │
动态道路供给估计                未来交通状态预测
车头时距 / 信号 / 下游约束       路网邻接 / 历史状态 / 环境
    │                               │
    └───────────────┬───────────────┘
                    ▼
         供需差额与失衡风险分析
                    │
       信号参数调度 + 动态路径分流
                    │
        SUMO / TraCI 双组仿真反馈
                    │
            网页可视化与评价
```

核心创新设计与演示对应关系：

1. **多环境扰动下的供需双向建模**：事件、雨天和需求变化同时作用于环境参数、供给约束和需求状态。
2. **考虑车辆自主化比例的供需协同预测**：混合交通容量先验结合历史路段状态、上下游邻接特征与环境状态，支持未来 5–60 分钟交通状态预测。
3. **可解释动态匹配与反馈评估**：根据供需缺口、排队和下游约束调度信号参数、调整路径，并记录调控动作与仿真指标。

**当前研究原型**采用混合车头时距供给估计、轻量图状态残差预测与预测驱动的信号/路径调控，并未宣称已实现 Transformer 或完整 MPC 最优控制；元胞模型与 Transformer 属于后续拓展与对比方向。

## 已有 Demo 的研究描述

据当前项目计划书，演示原型包括 Python、Flask、SUMO 1.27.1 与 TraCI，采用 Cologne8 的 **149 条道路边、8 个信号路口**；页面提供：

- 图结构道路交通状态可视化，查询流量、速度、密度和排队；
- 未来 12 个五分钟窗口（5–60 分钟）的交通状态预测；
- 事故瓶颈、雨天施工、需求突增的场景控制；
- 固定信号与智能调控两个相同输入条件下的仿真组；
- 策略日志、曲线与 JSON/CSV 结果导出。

上述是**计划书所记载的原型功能**。只有在后续源码、依赖与数据脚本发布并完成复现后，才视为本仓库可运行功能。

## 初步仿真结果（不等于现场实测）

根据项目计划书，每类场景 3 个随机种子，完整调控方案相对于固定信号方案报告：

| 场景 | 平均累计延误下降 | 排队积分平均下降 |
| --- | ---: | ---: |
| 事故瓶颈 | 18.24% | 23.19% |
| 雨天施工 | 5.41% | 9.68% |
| 需求突增 | 13.49% | 2.80% |

这些结果只对应选定路网和**合成交通条件**；并非全部指标均有提升，控制模块的独立贡献、容量估计真值与跨路网推广性仍需验证。源代码和原始实验输出未公开前，读者无法仅根据当前仓库复算上述数据。
